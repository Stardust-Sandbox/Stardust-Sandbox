---

> [!IMPORTANT]
>
> This project is a complete reimplementation of [Stardust Sandbox](https://github.com/Stardust-Sandbox/stardust-sandbox-legacy.git), now marked as `legacy`, using the C++ programming language (version 17) alongside libraries such as [SDL3](https://wiki.libsdl.org/SDL3/FrontPage).

---

> [!WARNING]
>
> The reimplementation of Stardust Sandbox is still in progress and is currently in an early stage of development. Therefore, significant changes to the source code and project structure are expected over time. Additionally, the documentation is still being written, meaning that some information may be incomplete or outdated.

---

> [!NOTE]
>
> Since the project is still under development, if you would like to check out the original version of Stardust Sandbox, you can access the legacy repository by [clicking here](https://github.com/Stardust-Sandbox/stardust-sandbox-legacy.git). More information about the project's restructuring will be made available soon, including details about the reasons for the reimplementation, the planned improvements, and the differences between the original version and the new version currently under development.
